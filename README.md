# PFPU Warehouse Manager

Warehouse inventory, asset tracking, job preparation, and equipment management software developed for **Power Factory Productions**.

> **Development Status:** Pre-release / active testing
> **Current Version:** 0.1.0

---

## Overview

PFPU Warehouse Manager is a web-based warehouse management system designed around the workflow of a production and audio equipment warehouse.

The system provides a central location for managing:

- Equipment inventory
- Individually tracked assets
- QR asset labels
- Warehouse storage locations
- Jobs and equipment reservations
- Equipment preparation and loading
- Equipment returns
- Repairs and inspections
- Lost/found equipment
- Inventory audits
- Users, roles, and permissions
- Backups and recovery

The PFPU server runs on a Windows computer and is accessed through a web browser by warehouse computers, tablets, and other devices on the local network.

---

# Current Features

## Inventory Management

PFPU maintains a master inventory containing equipment descriptions, categories, quantities, values, tracking priorities, and Asset ID prefixes.

Inventory can be searched and individual equipment types can be opened to view their warehouse and asset information.
